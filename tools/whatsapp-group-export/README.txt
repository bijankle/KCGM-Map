WHATSAPP GROUP CONTACTS EXPORT (Chrome or Edge on Windows)

INSTALL (one time)
1. Download this whatsapp-group-export folder to your PC, for example to Documents.
2. In Chrome go to chrome://extensions (in Edge go to edge://extensions).
3. Turn on Developer mode (top right in Chrome, left side in Edge).
4. Click "Load unpacked" and pick the whatsapp-group-export folder.

USE
1. Open https://web.whatsapp.com and log in.
2. Click the group you want.
3. Click the green "Export group CSV" button in the bottom right corner.
4. The CSV lands in your Downloads folder, named after the group.

COLUMNS
Name, WhatsApp name, Phone, Role, Saved in my contacts.

NOTES
Phone numbers include the country code. If Excel shows them as 4.47701E+11,
select the Phone column, then set Format Cells to Number with 0 decimals.
If WhatsApp hides some members' numbers in a group, those rows show a name only.
If WhatsApp changes its site and the full read fails, the button falls back to
the member line under the group name, which gives names and unsaved numbers only.
